# @smithable/adapter-tanstack

Generates TanStack Start + Drizzle applications from the Smithable IR.

This package is part of [Smithable](https://smithable.ai). You normally don't install it directly: the `smithable` command (`npx smithable@latest new my-app`) brings it with it.

- Website: https://smithable.ai
- Documentation: https://docs.smithable.ai
- Source and issues: https://github.com/smithable/smithable

Licence: Apache-2.0, with the app kit and templates under 0BSD, so generated apps carry no obligations.
