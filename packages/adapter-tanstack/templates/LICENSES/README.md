# Third-party notices

This folder keeps the licence texts of code copied into the app's source, so they travel with
every copy of the app, in the container image too. Libraries installed from npm carry their
own licences in `node_modules/`.

- `shadcn-ui.txt`: the components in `src/components/ui/` (MIT).

The app kit in `src/kit/` comes under the Zero-Clause BSD licence, which asks nothing of you;
the generated code is yours.
