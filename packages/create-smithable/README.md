# create-smithable

`npm create smithable` starts a [Smithable](https://smithable.ai) app. It runs `smithable new` for you:

```sh
npm create smithable my-crm                          # a CRM from the starter, with sample data
npm create smithable my-site -- --starter booking    # or marketplace, invoicing, records, status, api
```

Then `cd my-crm && npx smithable studio` opens the editor in the browser. Smithable needs Node 24.
