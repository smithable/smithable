Keys

For other programs that use this app's API. A key acts with its role and owns nothing.

In the preview a key works only on this computer: other programs and assistants reach the app with it once it is published.

Using a key

The API is at http://localhost:8404/api/v1, described at http://localhost:8404/api/v1/openapi.json. Download the description

A first call:

curl -H "Authorization: Bearer <key>" http://localhost:8404/api/v1/projects

For an AI assistant: the tools are at http://localhost:8404/mcp. Its settings need:

{
  "mcpServers": {
    "team-tasks": {
      "type": "http",
      "url": "http://localhost:8404/mcp",
      "headers": {
        "Authorization": "Bearer <key>"
      }
    }
  }
}
