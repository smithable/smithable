# Spec drafts

Full-vision drafts of three sample apps, written to test the spec design against different kinds of applications:

- `crm/`: an internal tool with relations, a status workflow, a formula, a custom action and a dashboard.
- `booking/`: a public site with per-user bookings, a calendar and a landing page.
- `invoicing/`: a SaaS with a marketing page, per-user data and formulas.

They use constructs that later spec versions will add. The specs that validate today live in `examples/` and grow milestone by milestone towards these drafts.
