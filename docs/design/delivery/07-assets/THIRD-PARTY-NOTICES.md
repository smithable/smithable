The app kit's original code/design can use 0BSD while retaining separately applicable dependency notices.

Google and Facebook are text labels identifying potential sign-in providers; no third-party logo artwork is included. No bespoke photography is included. The supplemental concept board is AI-generated using the built-in image-generation tool; exact implementation values are defined by the vector screens and tokens.
